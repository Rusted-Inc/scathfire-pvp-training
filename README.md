# Scathfire's PvP Training

A Fabric mod for Minecraft Java **26.3** that turns Minecraft into a PvP training game.

- A branded intro and a **PvP World** button on the title screen
- One click makes (or opens) the PvP World with a grid-paper hub
- Press **P** for the training menu: **Fight a Bot** (5 modes, 5 levels), **Drills**, and **Coach tips**
- The coach gives tips after every session, with optional smarter AI tips through a free OpenRouter key

The bots, arenas and drills run on [Carpet PvP](https://github.com/AndrewCTF/Carpet-PvP) (Apache 2.0), which is installed next to this mod. See [CREDITS.md](CREDITS.md).

## Get it

Every push builds the mod on GitHub. Open the **Actions** tab, click the newest green run, and download
**scathfire-pvp-training** at the bottom. Install steps are in [INSTALL.md](INSTALL.md).

## Build it yourself

You need Java 25. Run `./gradlew build`. The jar is in `build/libs/`.
