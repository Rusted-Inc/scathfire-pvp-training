# Install Scathfire's PvP Training

You need Minecraft Java Edition **26.3**.

1. Install **Fabric Loader** for 26.3 from https://fabricmc.net/use/installer/
2. Download **Fabric API** for 26.3 from https://modrinth.com/mod/fabric-api
3. Put these in your `.minecraft/mods` folder:
   - `scathfire-pvp-training-<version>.jar` (this mod)
   - `carpet-pvp-26.3-<version>.jar` (the bot engine). If it isn't in this download, get the 26.3 file from
     https://modrinth.com/mod/carpet-pvp-practice
   - the Fabric API jar
4. Start Minecraft with the Fabric profile.
5. Click **PvP World** on the title screen.

In the PvP World, press **P** any time to open the training menu.

## Optional extras

## AI Coach (optional)

The coach gives tips after your fights without any setup. For smarter tips from an AI, get a free key at
https://openrouter.ai/keys and paste it in the menu under **Coach > Settings**.
